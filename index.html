Activate the Catalyst license

Confirm it's assigned to the right user

In License Manager, check the license shows under the correct person's Trimble ID — that's the login the crew signs into TMM / TerraFlex with.

i
Who should the license be assigned to?
  • One person on the unit: assign it directly to their email — they'll make their own Trimble ID with that address.
  • Several people, one unit: either reassign the license to each user when needed, or set up a single shared Trimble ID (a generic team email) that everyone signs in with using the same username and password.
  • Multiple licenses and multiple people: create several generic Trimble IDs and drop a laminated card with each one's username and password in its kit box — or just reassign licenses manually as they change hands.

Install Trimble Mobile Manager (TMM)

Free, and the first thing to set up. You need it for Field Maps (and any third-party app) and for DA2 firmware updates. Using only TerraFlex? You can skip TMM — see Phase 3.

2
Power on & mount
Get the DA2 powered and positioned for a clear sky view.

Connect power

Plug the power bank into the DA2's USB-C port.

Press the power button until the LED blinks blue

A blinking blue LED means the DA2 is discoverable over Bluetooth and ready to pair.

Mount it high, with sky overhead

For precision work (10 cm or better) Trimble recommends a 2 m or taller pole. Keep the antenna above head height and pointed at the sky.

Trimble Mobile Manager
Activates Catalyst and configures the receiver for Field Maps and any third-party app. TerraFlex users can skip to Phase 4.
i
Collecting in TerraFlex only? Skip this whole phase — TerraFlex connects to the DA2 and handles your Catalyst sign-in itself. You'd only open TMM to apply a DA2 firmware update.

Sign in with your Trimble ID

Open TMM and sign in with the ID that has the Catalyst license assigned to it.

Pair the DA2, then connect in TMM

With the DA2's LED blinking blue, pair it in your device's Settings → Bluetooth. Then open TMM → Position Source and select the DA2 (match the serial number on the label). Once selected, TMM connects and shows the receiver, satellites, and live accuracy.

Set the GNSS configuration

Open GNSS configuration and apply the settings below. These are recommended defaults for U.S. / Texas (CONUS) mapping work.

i

Start your Catalyst session

If you're on an On-Demand hour pack, start the session under Licenses so corrections begin streaming. Subscription plans are always-on. Leave TMM running in the background.

4
Connect your software
Keep TMM running, then set up the app you're collecting in.

Confirm TMM is connected first

The DA2 must already be configured and connected in TMM (Phase 3). Don't use the Trimble GNSS Status app — TMM is the one that talks to Field Maps.

Add Trimble Mobile Manager as the location provider

In Field Maps go to Profile → Location provider → Add and choose Trimble Mobile Manager — not the DA2 directly. Every Trimble receiver you have then appears on the provider screen, so pick the unit you want. If you run two DA2s, both show up — just select the right one. TMM passes through the rest: receiver model, live accuracy, and pole height.

There's nothing else to set on the receiver — TMM handles it

Current Field Maps versions expose no configurable fields for Trimble GNSS units. The receiver details and your pole/antenna height flow in from TMM — so set the pole height back in TMM (Phase 3), not here.

Build your location profile

This is what makes DA2 positions line up on your basemap. Build it in this order:

  1. Set the GNSS coordinate system — search by its EPSG code (6318) rather than the name; it's faster and avoids picking the wrong one. This matches the DA2 output you set in TMM.
  2. Set the map coordinate system the same way — search the EPSG code 3857 for Web Mercator, matching your basemap.
  3. Zoom into your data-collection area on the map first. Datum transformations are region-specific, so only the relevant ones show up once you're zoomed in.
  4. Pick the datum transformation, then name the profile. Naming it after the conversion — e.g. 6318 to 3857 — makes it easy to recognize next time.

Check the accuracy banner, then collect

Open your map. The GPS banner should report DA2-level accuracy. Once it converges, start adding points.

Pair the DA2 in Bluetooth settings first

With the DA2's LED blinking blue, pair it in your device's Settings → Bluetooth before you open TerraFlex — it connects to a DA2 that's already paired with the phone or tablet.

Sign in to TerraFlex

Open TerraFlex and sign in with your Trimble ID — the login that has your Catalyst license assigned.

Select your project

TerraFlex asks you to pick a project first. Choose the one you're collecting into — it loads that project's layers and forms before you land on the Home screen.

Connect to the DA2 from the Home screen

On the Home screen, tap the Location status tile (Trimble DA2). TerraFlex lists nearby receivers by model + serial number — tap your DA2 to connect. If it shows Connection failed, tap Reconnect. Then open GNSS configuration for the settings below.

Enter antenna height & measurement point

In the Antenna height field, enter your measured height and pick the measurement point you used. Catalyst Handle: if you measured to the bottom of the handle, add 2.3 cm.

Real-time corrections — already set up

Nothing to configure here. Real-time corrections come automatically with your Catalyst license — just confirm the Location status tile is showing the accuracy you expect.

(Optional) Offline post-processing — TerraFlex Premium only

Offline GNSS post-processing requires a TerraFlex Premium license. If you have it and plan to use it, set Primary Display Value to After offline GNSS processing so the accuracy you see reflects the processed result.

★
In the field: best accuracy
Habits that keep your numbers tight.

Let it converge before the first point

Give the receiver a few minutes to refine — longer under canopy or cloud. Watch the live accuracy in TMM and wait until it settles within your job's tolerance.

Keep the antenna upright and clear

Hold the pole vertical and the antenna above head height. Don't let your body, vehicles, or buildings shadow the sky view — that's the #1 cause of poor positions.

Initialize in the open, then move into cover

Let the receiver converge to full accuracy where it has a clear view of the sky first. Once it's locked in, you can move into tougher spots — under canopy or close to buildings — and hold a solid solution. Catalyst's RTX corrections are delivered by satellite, not just over the internet, so you keep a correction stream even with no cell signal.

Troubleshooting
The issues field crews hit most.
A. Field Maps is stuck on "Acquiring location" ▸
  1. Fully close both Field Maps and TMM (swipe them away).
  2. Open TMM first: sign in and connect to the DA2 — wait until you see live accuracy.
  3. Confirm the correction source is set to Auto.
  4. With TMM still running, open Field Maps and reselect Trimble Mobile Manager (and your DA2) as the location provider.
B. Accuracy is way worse than TMM reports ▸
Usually the app is reading the phone's built-in GPS, not the DA2. In Field Maps, confirm Trimble Mobile Manager is the selected location provider and that you've picked the right receiver on the provider screen — if you run more than one DA2, it's easy to land on the wrong unit. Also confirm TMM is running and connected, the DA2 is paired in your device's Bluetooth settings, and the antenna is clear of obstructions.
C. Recorded points are shifted a few feet from a known control point ▸
That's almost always a datum or geoid mismatch. Make sure the TMM output (NAD83 2011, GEOID18) matches your map's coordinate system and any transformation in Field Maps. A consistent offset in X/Y/Z is the classic symptom.
D. The DA2 won't show up over Bluetooth ▸
  1. Confirm the LED is blinking blue (discoverable). If not, hold power to power-cycle.
  2. Make sure the power bank is actually delivering power — the DA2 has no battery.
  3. Pair the DA2 in your device's Settings → Bluetooth first, then open the app.
  4. Forget any old DA2 pairing on the device, then re-pair. If needed, reset the DA2 by holding power until the LED turns off, then power back on.
